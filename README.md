# 🧮 Arbitrary Precision Calculator

## 📌 Project Overview

The **Arbitrary Precision Calculator (APC)** is a C-based calculator designed to perform arithmetic operations on **very large integers** that cannot be handled by standard C integer data types.

The project implements arithmetic operations using **linked lists**, allowing numbers of large size to be processed without overflow limitations.

## ⚙️ Features

* Addition of large numbers
* Subtraction of large numbers
* Multiplication of large numbers
* Division of large numbers
* Supports numbers beyond standard integer limits
* Command-line based input
* Handles positive and negative numbers

## 🛠️ Technologies & Concepts

* C Programming
* Data Structures
* Linked Lists
* Pointers
* Dynamic Memory Allocation
* String Processing
* Command-Line Arguments
* Modular Programming

## 🔄 Working

Large numbers are stored as **linked lists**, with each node representing part of the number. Arithmetic operations are performed on these linked-list representations instead of using standard integer data types.

This approach allows the calculator to process numbers much larger than the limits of `int`, `long`, or `long long`.

## 🎯 Challenges

* Handling numbers larger than standard data types
* Implementing arithmetic operations using linked lists
* Managing positive and negative numbers
* Handling carry and borrow operations
* Managing dynamic memory efficiently
